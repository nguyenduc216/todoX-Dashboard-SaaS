## 2. Chưa làm / cần anh quyết

1. **Giá giọng đọc trên production đang là 0,5 point/lần** (bảng giá voice premium trong dashboard), không phải 800 như mặc định cài đặt. Nếu muốn 800 point/lần: vào trang cấu hình giá point của dashboard, sửa Voice premium = 800. Tool tự lấy giá mới.
2. **Clone giọng cá nhân**: chưa làm — chưa xác minh Vbee có API clone. Hiện dùng giọng có sẵn trong danh mục AI Studio.
3. **Kiểm tra số dư tài khoản Vbee chủ động**: Vbee không có API số dư trong code hiện có; hệ thống phát hiện khi Vbee từ chối (hết tiền / quota) và báo admin ngay.
4. **Làm cứng exe (NativeAOT/obfuscator)**: chưa làm — giao diện WinForms không tương thích NativeAOT. Bù lại, toàn bộ logic dựng đã chuyển lên server nên exe gần như không còn bí quyết.
5. **Chữ ký số**: chưa có → Windows cảnh báo "Unknown publisher" (đã ghi rõ hướng dẫn + liên hệ trong cửa sổ, trang khách và landing).
6. **Merge vào `main`**: chưa (theo C10).
7. **License Remotion**: cần mua Company License trước khi bán.

## 3. Đã thay đổi trên máy dev này (khi test như khách)

- Cài TodoX EditVideo vào `%LOCALAPPDATA%\TodoX\EditVideoTool`, shortcut Desktop/Start menu.
- Đăng ký MCP `todox` vào Claude Desktop, Claude Code (`~/.claude.json`) và Codex (`~/.codex/config.toml`); có bản sao lưu `*.todox-backup`.
- Skill `todox-video` trong `~/.claude/skills` và `~/.codex/skills`.
- Gỡ: Settings → Apps → "TodoX EditVideo" → Uninstall (hoặc `todox-editvideo.exe uninstall`).
- Máy này đang giữ slot máy tính của key thử.
